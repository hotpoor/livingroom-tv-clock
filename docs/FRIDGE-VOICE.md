# 语音更新冰箱库存

入口：右侧冰箱面板顶部「语音」，或菜单「语音更新冰箱」。先选择冰箱有助于匹配食材简称，稍后也可在核对页选择。按住遥控器语音键，看到收音提示后再说完整一句，说完按返回收起键盘，选择「解析并核对」。

例如：

- 「放进了两盒红颜草莓酸奶」
- 「冷冻的牛肉烧卖吃掉了三个」
- 「上部冷藏放进酸奶五盒，保质期20300101-20300110」

每次处理一种食材和一个操作。整数数量和增减方向由程序识别；模型只提取完整食材名。电视同时发送结构化库存摘要给局域网服务：冰箱名、完整品名、当前余量、单位、分区和到期日期。摘要优先包括所选冰箱或语音提到的冰箱，最多 20 台冰箱、32 条食材记录。语音解析接口只返回草稿，不保存输入文字；用户确认后电视更新本机库存，再通过独立的库存同步接口同步到服务端。

库存摘要同时用于规则匹配和模型提示。能唯一匹配时，会把「草莓酸奶」等简称补全为已有完整品名并显示提示，参考同名食材补出分区。「2楼」与「二楼」、名称中的“的”和空格会归一化；冰箱可以说在句尾，语音指定的冰箱优先于输入页默认值。多个候选、多个分区或批次时需要人工选择。已说出的数量、单位和位置不会被模型覆盖。匹配库存后仍显示原话，补全结果可在核对页修改。

明确说出冷藏、冷冻、上层等分区时按原话选中。新食材没有明确分区时，会参考所选冰箱中相近品名或同类食材，显示候选分区、参考食材和相似匹配度，可点击采用。分数是字符串相似度与共享品类关键词的启发式评分，不是经过统计校准的概率，也不是通用食品储存建议；不明确时不会替用户自动选定分区。

核对页可选择冰箱、放入／吃掉、具体批次、数量、单位、分区及可选保质期。点击「核对变更」会再次显示目标冰箱、食材和“原库存 → 新库存”；只有再点「确认更新」才修改库存。

## 批次与数量

- 放入命中唯一的已有批次，且单位、分区及明确提供的保质期相符时自动选中，显示当前数量与原保质期供核对。多个批次或单位不符时需选择已有批次或新增；不做单位换算。
- 新食材、明确说「新批次」、或提供与旧批次不同的保质期时，选择独立新批次。也可手动切换到「作为新食材 / 新批次放入」。
- 新批次不继承旧批次的保质期。日期不知道可留空，显示「尽快食用」。可以只填到期日期，也可以填开始及到期日期；格式为 YYYY-MM-DD。
- 吃掉需要选已有批次。只有品名、单位、分区匹配且批次唯一时才预选；同名多批次不自动扣减。
- 原话的「盒」与库存的「个」不做单位换算。单位不同时需要明确选批次，并按该批次单位核对数量。
- 数量必须为 1–9999 的整数；暂不处理半盒、重量或“吃完剩下所有”等不明确数量。库存不足时拒绝更新，归零后移出该批次。
- 核对期间库存被其他操作修改时，会拒绝旧草稿并要求重新核对。返回、取消、缺少动作／数量／目标批次都不更新库存。

语音转写漏掉开头时，例如只收到「了两盒酸奶」，会清理名称前残留的“了”并提示选择增减方向，程序不推测漏掉的是放入还是吃掉。

## 部署和验证

沿用 [语音日程服务](VOICE.md) 的配置、口令与局域网地址。更新服务时一并部署 `server.py`、`schedule_parser.py`、`fridge_parser.py` 和 `fridge_context.py`。新增草稿接口 `POST /fridge/parse`：

服务主机需要保持局域网可达。macOS 闲置休眠会让自定义端口暂时无法连接；可用 `caffeinate -i python server.py` 在服务运行时防止系统闲置休眠，显示器休眠设置照常生效。

```json
{"text":"放进两盒草莓酸奶","inventoryContext":{"preferredFridgeId":"example","fridges":[{"id":"example","name":"厨房冰箱","items":[{"name":"示例草莓酸奶","quantity":3,"unit":"盒","location":"上部冷藏","endDate":"2030-01-10"}]}]}}
```

服务返回 `food/action/quantity/unit/fridgeName/fridgeId/fridgeMatched/location/locationSource/locationSuggestionsByFridge/startDate/endDate/issues/unsupported/contextUsed/foodCandidates/modelUsed/requiresConfirmation`。缺失字段需在电视补齐，多食材、多操作草稿会要求分开输入。确认后先更新电视本机，再同步至局域网共享库存。网页与电视的并发修改使用版本校验，冲突留待网页核对。

```powershell
python -m unittest discover -s backend -v
./verify.ps1
./checks/run-device-checks.ps1 -TvAddress YOUR_TV_IP:5555 -Mode fridge
```

设备检查会临时建立独立的测试冰箱，验证草稿、预览和取消不写入库存，新增、指定批次扣减、归零、补货、库存不足、单位不符、旧版本冲突、上下文补全与语音截断处理。结束后删除测试冰箱并检查其他家庭库存保持一致；临时测试 APK 也会卸载。

需要用某条输入复现现有库存的自动选择时，可加 `-ReplayText '你的原话' -ExpectedFridge '目标冰箱' -ExpectedFood '完整品名'`。该模式只打开草稿、检查冰箱与已有批次、显示预览后返回，不确认更新，也不建立测试冰箱。
