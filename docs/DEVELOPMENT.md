# 开发记录

2026-10-20，从 Android 9 小米电视的 ADB 可用性检查开始，完成原生家庭信息屏的第一轮实现。

| 版本 | 内容 |
| --- | --- |
| 0.1.0 | 翻页时钟、宝山天气、自动定位回退、小米屏保广播接入 |
| 0.2.0 | 分组设置、屏保亮度、夜间调暗、公历和农历开关 |
| 0.2.1 | 公历补全年份 |
| 0.3.0 | 冰箱侧栏、横向 Tab、新增/更名/删除、本机持久化 |
| 0.4.0 | JSON 库存、冷藏/冷冻卡片、数量与日期、三分之一侧栏、自适应时钟 |
| 0.5.0 | 左侧日程、出发/开始/当日截止倒计时、事项编辑与本机提醒 |
| 0.5.1 | 前台遥控器语音输入测试页，通过输入法观察文字是否回填；不录音、不保存测试文字 |

真机发现固件的标准 Dream 配置关闭，实际屏保来自小米应用。接入 `com.duokan.intent.action.show.screensaver` 与退出广播，临时缩短空闲时间验证自动启动后恢复原值。没有删除原厂应用或取得 root。

曾出现侧栏打开后整张时钟被缩小的问题，已改为根据剩余宽度计算卡片位置和大小，公历、农历分行，文字保持可读尺寸。

公开仓库只保存通用代码和空白示例。实测家庭数据、电视地址、调试截图和签名留在本机。

## 后续方向

- 库存 JSON 的显式导入/导出与食材编辑。
- 多设备数据同步，以及导入的版本和冲突处理。
- 小爱语音入口的实际固件适配，当前未实现。
- 更多电视固件的自动屏保、通知、休眠和遥控器焦点验证。
- 跨平台本地构建脚本；当前本地编译脚本面向 Windows，其他系统可使用 GitHub Actions。

## 语音输入兼容性检查

该真机未注册标准 `android.speech.RecognitionService` 或 `android.speech.action.RECOGNIZE_SPEECH` Activity。单靠标准 SpeechRecognizer 不能直接调用电视的小爱识别。

0.5.1 新增「设置 → 遥控器语音输入测试」。选中前台 EditText 后请求输入法，真机搜狗输入法成功建立 InputConnection，界面显示「按住语音键说话」。识别结果能否回填仍需用户实际按键说话验证。这里未接入小爱技能，也不将测试文字直接写入库存或日程。
